# Todo API (Django Rest Framewok)

A todo web app built with tech stack such as: Django Rest Framework(DRF) and PostgresSQL.

In the course of development, I explored the object relational mapper (ORM), and serializer, using a function based view with CRUD operations. The storage framework used are sqlite for test and PostgresSQL for production.

This is one of my hands-on experience with DRF, CRUD operations, database development and deployment.
